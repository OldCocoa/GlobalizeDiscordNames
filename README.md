# GlobalizeDiscordNames
GlobalizeDiscordNames is a tweak that patches Discord to use the new "global_name" attribute instead of "username".
# Why make this?
Discord's new display name feature is not supported on clients that were made before the change, so this means any client before ~2023. I wanted to have this feature on older client versions, so this tweak does exactly that.
# What versions does it support?
- [x] Discord 106.0 (Last iOS 10 version)

No other version has been tested, it could work for others.
